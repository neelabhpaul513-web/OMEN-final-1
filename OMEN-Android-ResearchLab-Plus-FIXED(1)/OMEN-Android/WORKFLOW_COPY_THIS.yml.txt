The canonical GitHub Actions workflow is already included at the ZIP root:
.github/workflows/build.yml

IMPORTANT: Upload the CONTENTS of this ZIP to the ROOT of your GitHub repository.
The repository root must contain both:
  .github/workflows/build.yml
  OMEN-Android/settings.gradle.kts

Do not upload the ZIP file itself to GitHub. Do not put the .github folder inside
another extra folder. Then open GitHub > Actions > Build OMEN APK and run the workflow.
The generated APK is available as the OMEN-debug-apk artifact.
