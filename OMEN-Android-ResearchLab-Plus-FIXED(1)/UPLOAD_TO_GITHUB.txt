OMEN – GitHub build instructions

1. Extract this ZIP.
2. Open the extracted folder. You should see:
     .github/
     OMEN-Android/
     UPLOAD_TO_GITHUB.txt
3. Upload the CONTENTS of this folder to the ROOT of your GitHub repository.
   Do not upload the ZIP itself, and do not place everything inside another folder.
4. Confirm these two paths exist in the repository:
     .github/workflows/build.yml
     OMEN-Android/settings.gradle.kts
5. Open the repository's Actions tab.
6. Choose "Build OMEN APK" and select "Run workflow".
7. When it succeeds, open the run and download the "OMEN-debug-apk" artifact.
8. Extract the artifact ZIP and install OMEN-debug.apk on your Android phone.

The project ZIP is source code, not an APK. It cannot be installed directly on Android.
If the build fails, download the "OMEN-build-diagnostics" artifact and share the
full first Gradle error from the run log so the Kotlin/Android source issue can be fixed.
